# Anuraj Singh Portfolio — React + Tailwind

A React/Vite + Tailwind CSS recreation of the minimalist portfolio design supplied in the original HTML.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Edit your content

Most portfolio content is in `src/data.js`.

Before deploying, replace:
- `your-email@example.com`
- GitHub `#`
- project `#` links
- `/public/assets/Anuraj_Singh_Resume.pdf` with your actual resume PDF
